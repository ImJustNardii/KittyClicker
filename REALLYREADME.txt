EPICWEB 2: THE CLICKENING
=========================

INSTALACION
1. Haz una copia de seguridad de tu carpeta actual.
2. Extrae index.html, style.css y este archivo en la misma carpeta donde ya tienes las imagenes y sonidos.
3. Abre index.html en el navegador o sube esos archivos a tu repositorio de GitHub Pages.
4. Conserva los nombres originales de tus recursos. No borres tus PNG, GIF ni MP3.

RECURSOS QUE USA LA WEB
- imagen.png: imagen principal del gatito.
- perro.png: imagen del perro dorado/enemigo.
- loader.png: icono de carga.
- logros.png: icono del panel de logros (si falta, usa imagen.png).
- logro-click.png: icono genérico de respaldo si falta un icono individual.
- logro-secreto.png: icono para logros secretos mientras están bloqueados.
- gato-deluxe.png: imagen que tú elijas para la skin Gatito deluxe; no se le aplica filtro automático.
- logro-<ID>.png: icono individual de cada logro. Revisa la lista completa de nombres debajo.
- explosion.gif: animacion de explosion por spam.
- credits.png: imagen de creditos.
- sonido.mp3 y sonido-perro.mp3: sonidos de las skins de gato y perro. Las variantes de cada animal comparten su SFX.
- logro.mp3 y logro-completo.mp3: sonidos de logros.
Solo las skins doradas reciben automáticamente un filtro amarillo/dorado. Las demás imágenes se usan tal cual, para que tú elijas el arte. No hay radio ni se carga ningún archivo de música de radio.

GUARDADO
El progreso se guarda en localStorage del navegador. Por eso no se sincroniza automáticamente entre dispositivos ni navegadores.
